Descrição do Projeto

Projeto focado no aprendizado dos conceitos fundamentais de lógica de programação e temporização. Ele simula o comportamento real de um semáforo de trânsito para carros e pedestres, utilizando LEDs organizados sequencialmente.

Componentes Utilizados

  • 1x Placa Arduino Uno
  • 3x LEDs de 5mm (Vermelho, Amarelo e Verde) para o sinal dos carros
  • 2x LEDs de 5mm (Vermelho e Verde) para o sinal dos pedestres
  • 5x Resistores de 220Ω
  • 1x Botão Pushbutton (opcional, para travessia de pedestres)
  • Protoboard e Jumpers

Como Funciona

O microcontrolador gerencia o estado dos LEDs utilizando a função de temporização (`delay` ou `millis`). O código alterna o acendimento dos LEDs na ordem padrão: Verde (Aberto) -> Amarelo (Atenção) -> Vermelho (Fechado). Se integrado com um botão de travessia, o programa interrompe o fluxo normal para permitir a passagem segura de pedestres.
